# Результаты занятия 9

Замеры выполнены 24 ноября 2026 года в ветке `module-05`.

- `rag_stub.txt` — настоящий офлайн-запуск `python rag_stub.py`: ответы мини-базы с источниками и отказ на вопрос про отпуск.
- `simple_chain.txt` — настоящий запуск `python simple_chain.py` с GigaChat-2: категория, действие, ответ и список источников для каждого из пяти обращений.
- `self_checks.txt` — офлайн-самопроверка парсера и маршрутизации с локальным Runnable вместо API. Проверены четыре звена classify-цепочки, ответы базы, отсутствие источников и отсутствие вызовов в неизвестной ветке. Это дополнительная проверка к живому прогону.
- `environment.txt` — установленные версии четырёх зависимостей из `requirements.txt`.

Повторить обязательные прогоны из корня репозитория на macOS:

```bash
source venv/bin/activate
pip install -r module_05/requirements.txt
cd module_05
python rag_stub.py
python simple_chain.py
```

Для последней команды нужен существующий `GIGACHAT_CREDENTIALS` в корневом `.env`. Текст генерируемых ответов может отличаться. Для ответа из базы проверяются непустые источники, для инцидента и доступа — генерация и действие «специалисту», для отпуска — отказ и пустые источники.

Итоги и разбор неоднозначного обращения записаны в корневом `REFLECTION.md`. Требуемое название коммита: `Занятие 9: цепочка LCEL сценария ПромТеха`. Pull Request по методичке создаётся в конце занятия 10.
