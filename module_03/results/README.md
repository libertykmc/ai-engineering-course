# Замеры занятия 6

Эксперименты используют исходные 11 вопросов из `data/questions.json` и локальную модель `paraphrase-multilingual-MiniLM-L12-v2`. Результаты измерены на CPU; сервер Qdrant 1.18.3 работает в Docker. Версии Python-библиотек указаны в `../requirements.txt`.

Из корня репозитория на macOS:

```bash
source venv/bin/activate
pip install -r module_03/requirements.txt
cd module_03
docker compose up -d
python run_experiments.py
```

`reference_*.txt` содержат полную выдачу с фильтром и без него, две метрики top-3, базовую линию по целым документам, сравнение score вопросов из базы и ловушек, проверку payload и нахлёста. `my_600_150.txt` — такой же прогон на собственной генерации занятия 5. `metrics.json` содержит сводку и результаты каждого контрольного вопроса. `final_index.txt` подтверждает восстановление эталонного индекса 600/150 после экспериментов.

`data/corpus/` — эталон из комплекта курса, `data/corpus_my/` — сохранённый собственный корпус до начала занятия 6. Скрипт временно выбирает другой корпус через `corpus_loader.CORPUS_DIR`, поэтому переименовывать папки для повторного замера не требуется.

Для обычного запуска после экспериментов:

```bash
python ingestion.py
python vector_store.py
```

Актуальное имя коллекции и отпечаток корпуса записываются в `data/index_manifest.json`. Новая сборка меняет время и имя коллекции, поэтому повторный запуск обновляет манифест и логи.
